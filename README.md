# Шифратор текста на Python

Школьный проект для 8 класса: программа с оконным интерфейсом (GUI),
которая умеет шифровать и расшифровывать текст **семью** шифрами:

1. **Шифр Цезаря** — сдвиг на N позиций по алфавиту.
2. **Шифр Виженера** — шифрование ключевым словом.
3. **Шифр Атбаш** — зеркальный алфавит.
4. **Шифр ROT13** — частный случай Цезаря (сдвиг на 13).
5. **Шифр Плейфера** — шифрование парами букв по таблице 5x5 / 6x6.
6. **Шифр Хилла** — шифрование парами букв с помощью матрицы 2x2.
7. **Шифр XOR** — современный подход «сложение» байтов с ключом.

Ещё в программе есть кнопка **«Взломать Цезаря»**: она подбирает сдвиг
методом частотного анализа — то есть расшифровывает текст **без ключа**
и показывает, почему старые шифры ненадёжны.

Программа поддерживает русский и английский алфавиты, умеет открывать
текст из файла, сохранять результат в файл и копировать его
в буфер обмена.

## Возможности программы

| Возможность | Как выглядит в окне |
|---|---|
| Поле ввода исходного текста | многострочное поле сверху |
| Поле результата | зелёный текст, редактировать нельзя |
| Выбор шифра | выпадающий список из 7 шифров |

## Требования

- Python **3.10 или новее**
- Дополнительные библиотеки не нужны — используется встроенный `tkinter`

Проверить, что Python установлен:

```bat
python --version
```

## Запуск

1. Скачай или скопируй папку проекта.
2. Открой командную строку (терминал):
   - **Windows:** нажми `Win + R`, введи `cmd`, нажми Enter.
   - **macOS / Linux:** открой приложение «Терминал».
3. Перейди в папку проекта:

```bat
cd shifrator
```

4. Запусти программу:

```bat
python main.py
```

> Если команда `python` не найдена, попробуй `python3 main.py`
> или `py -3 main.py` (Windows).

## Проверка шифров (тесты)

Запусти автоматические проверки:

```bat
python tests.py
```

Проверяется 34 пункта: все семь шифров (шифрование и расшифровка),
таблицы Плейфера, матрицы Хилла, частотный анализ и обработка
неверных ключей. Если в конце появится «Все проверки пройдены!» —
всё работает.

## Примеры

Исходный текст: **ПРИВЕТ**

| Шифр | Ключ | Результат |
|---|---|---|
| Цезарь | сдвиг 3 | ТУЛЕЗХ |
| Атбаш | не нужен | ПОЦЭЪМ |
| ROT13 | не нужен | ЬЭХОСЯ |
| Виженер | КЛЮЧ | ЪЬЖЩПЮ |
| Плейфер | ЛЕТО | ИЦРИТО (с добавленным «Х» в конце) |
| Хилл | АБВГ | РРВЧТБ |
| XOR | sun | a3ea... (шестнадцатеричный код) |

### Как пользоваться

1. Введи текст в верхнее поле.
2. Выбери шифр в списке — подсказка под полем ключа объяснит,
   какой ключ нужен.
3. Введи ключ (для Атбаша и ROT13 ключ не нужен).
4. Нажми «Зашифровать» (или `Ctrl + Enter`).
5. Чтобы вернуть текст обратно — вставь результат в верхнее поле
   и нажми «Расшифровать».

### Про ROT13 и русский текст

Для английского алфавита (26 букв) ROT13 «самообратный»: применить
его два раза — вернуть текст (13 + 13 = 26, полный оборот).

В русском алфавите 33 буквы, поэтому так не получается: программа
при расшифровке сдвигает буквы в обратную сторону. Кнопки
«Зашифровать» и «Расшифровать» работают правильно для обоих языков.

### Про букву «Х» в шифрах Плейфера

Плейфер (и Хилл) шифруют буквы **парами**. Если в слове нечётное число
букв, программа дополняет его служебной буквой «Х». При расшифровке
этот «Х» остаётся в конце слова — так работает классический Плейфер,
это не ошибка. Например, `ПРИВЕТ` расшифруется как `ПРИВЕТ`, а
`МИР` — как `МИРХ`.

### Как работают Плейфер и Хилл (коротко)

**Плейфер.** Из ключевого слова строится таблица с буквами. Текст
разбивается на пары букв, и каждая пара заменяется по трём правилам:
если буквы в одной строке — берём соседние справа, если в одном
столбце — соседние снизу, иначе достраиваем прямоугольник и меняем
буквы местами. Плейфером пользовались в Первую мировую войну.

**Хилл.** Ключ — это четыре буквы, из которых получается матрица 2x2.
Каждая пара букв превращается в столбик чисел, умножается на матрицу,
и снова превращается в буквы. Для расшифровки используется обратная
матрица. Это самый «математический» шифр проекта.

## Какие шифры быстрее взломать

| Шифр | Скорость | Как взламывают | Надёжность |
|---|---|---|---|
| Атбаш | мгновенно | одна таблица замен | минимальная |
| ROT13 | мгновенно | «применить ещё раз» | нет (это маскировка) |
| Цезарь | мгновенно | перебор 33 сдвигов или частотный анализ | очень низкая |
| Плейфер | быстро | перебор по парам букв (биграммам) | средняя |
| Виженер | быстро | частотный анализ + тест Казиски | средняя |
| Хилл | быстро | подбор матрицы, линейная алгебра | средняя |
| XOR | быстро | угадать повторяющийся ключ | высокая при длинном случайном ключе |
